# Lincheck Test Project

A standalone Gradle project with sample concurrent data structures and Lincheck tests. 
Used for manual QA of the [Lincheck plugin](https://plugins.jetbrains.com/plugin/24171-lincheck).

This project is not suitable for getting familiar with Lincheck as it uses synthetic structures which are rarely encountered
in real-life code. For a dedicated demo project that uses Lincheck, see the [`examples`](../examples/README.md) project.

This project is **not** part of the main build. Open it separately in IntelliJ IDEA with the Lincheck plugin installed 
to manually verify plugin functionality (trace visualization, scenario navigation, data structure diagrams, etc.).
