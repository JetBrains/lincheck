# Lincheck Demo Project

This is a dedicated demo project for Lincheck. The examples in this project are directly used in the [Lincheck
documentation](https://kotlinlang.org/docs/lincheck-guide.html). The documentation also provides detailed explanations
for every example.

If you want to explore this project locally, open it separately from the main `lincheck` project. To see the visualizations
for data structures and executions traces, install the [Lincheck plugin for IntelliJ IDEA](https://plugins.jetbrains.com/plugin/24171-lincheck).
